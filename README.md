# QUIPU Main Web 2025

서울시립대학교 컴퓨터 학술 중앙동아리 QUIPU의 2025년 메인 웹사이트 프로젝트입니다.  
동아리 소개, 모집 안내, 활동 정보 제공을 위한 공식 웹 서비스를 제공합니다.

## Overview

본 프로젝트는 QUIPU의 대외 안내 채널을 일관된 웹 경험으로 제공하기 위해 개발되었습니다.  
프론트엔드는 Next.js 기반으로 구성되어 콘텐츠 중심의 페이지를 제공합니다.  
백엔드는 Express API 서버로 동작하며, 모집 및 운영 관련 데이터를 관리합니다.

## Features

- 동아리 소개 및 활동 정보 제공
- 신규 회원 모집 페이지 제공
- 기술 스택 및 프로젝트 활동 소개
- 임원진 인터뷰 콘텐츠 제공

## Tech Stack

- Frontend: Next.js
- Backend: Express
- Database: MySQL

## Getting Started

### Install

```bash
cd frontend && npm install
cd ../backend && npm install
```

### Run

```bash
# backend
cd backend
npm start

# frontend
cd ../frontend
npm run dev
```
